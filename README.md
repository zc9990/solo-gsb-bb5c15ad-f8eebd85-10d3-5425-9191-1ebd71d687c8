# 走位轨迹碰撞排练台（Trajectory Collision Stage）

为 2～8 名表演者设置身体半径、在时间轴上编辑带时刻的二维走位点，系统对**分段匀速直线运动**做**解析级**任意时刻碰撞区间求解（二次方程求根，**不做离散帧抽样**），并在 Canvas 舞台上播放全程、高亮危险当事人、报告首次碰撞时刻与全程最小间距。

## 一键启动（Docker Compose）

依赖初始化（`npm install`）在镜像构建时自动完成，无需手动安装：

```bash
docker compose up --build -d
```

启动后访问：

- **http://localhost:3000**

停止：

```bash
docker compose down
```

> 端口占用时改为其他端口：编辑 `docker-compose.yml` 中 `ports`，例如 `"8080:3000"`，随后访问 http://localhost:8080 。容器内监听端口由环境变量 `PORT` 控制（默认 3000，与右侧映射保持一致）。

## 不用 Docker 的启动方式

需要本机已安装 **Node.js ≥ 18**。首次运行会自动安装依赖：

```bash
npm install
npm start
```

同样访问 http://localhost:3000 。

也可以自定义端口：

```bash
PORT=8080 npm start
```

## 必要配置（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 服务监听端口 |
| `HOST` | `0.0.0.0` | 监听地址，容器场景保持默认即可 |

## 使用方法

- 顶部工具栏：**播放/暂停**、回到起点、0.25×～2× 倍速、当前时刻时钟、恢复内置样例、服务端复算。
- 左侧上方为 **20m × 12m 舞台**：
  - 拖动任意**菱形走位点**立即改变位置，碰撞结果即时重算。
  - 在右侧列表选中一名表演者后，**双击舞台空白处**可在当前时刻补点；**双击走位点**删点（每人至少保留 1 个）。
  - 播放过程中，处于碰撞区间的表演者会红色脉冲高亮，碰撞双方以红色虚线相连。
- 左侧下方为 **时间轴**：
  - 拖动泳道内的菱形点改变该走位点的**时刻**；双击轨道空白处在该时刻补点；双击点删点。
  - 顶部红色横条为全程所有碰撞区间汇总，可直接拖动播放头定位。
- 右侧面板：
  - **表演者**：人数 2～8，可调整每人身体半径 `r`（0.05～5m）、添加/删除表演者。
  - **碰撞报告**：全程**首次碰撞时刻**及当事人、**全程最小间距**及发生时刻/当事人，并按每一对表演者列出全部碰撞时间段与最小间距。
- 内置一组**路径交叉样例**（4 人）：甲水平横穿、乙竖直纵穿，两人在 **t=5.00s** 于舞台正中相撞（间距 0）；丙斜线穿插与甲、乙分别形成擦碰区间；丁晚出发反向横移，全程保持安全余量。

## 碰撞算法说明（精确，非帧抽样）

每名表演者在相邻走位点之间做匀速直线运动，首点之前/末点之后保持静止。将两人所有关键时刻合并为分段事件；在每段事件区间内，两人的相对位置是时间的一次函数，碰撞条件

```
|P_i(t) − P_j(t)|² ≤ (r_i + r_j)²
```

退化为一元二次方程 `a·t² + 2b·t + c = 0`，由判别式与求根公式得到该区间内**连续的碰撞时间区间**（相对速度为 0 时按静态距离处理），最后合并跨分段边界的区间。同一份求解代码（`lib/collision.js`）同时被前端与服务端使用，可用界面上的「☁ 服务端复算」按钮交叉校验。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/sample` | 获取内置路径交叉样例 |
| `POST` | `/api/analyze` | 服务端复算：`{"performers":[{"radius":0.5,"points":[{"time":0,"x":2,"y":6}, ...]}]}` |
| `GET` | `/api/health` | 健康检查 |

快速验证：

```bash
curl -s http://localhost:3000/api/sample | curl -s -X POST http://localhost:3000/api/analyze \
  -H 'Content-Type: application/json' -d @-
```
